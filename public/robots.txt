# Only "/" has content worth indexing. Every other route serves the same
# client-rendered shell over the visitor's own local data, so indexing them
# yields a set of near-identical thin pages and nothing else.
#
# Those routes are deliberately NOT disallowed here. A disallowed URL can still
# be indexed — without a snippet, as a bare link — when something points at it,
# and the landing page's "Open app" button points at /dashboard. Keeping them
# crawlable is what lets a crawler read the `X-Robots-Tag: noindex` header
# vercel.json sends for each of them, which is the instruction that actually
# keeps them out of the index. Disallow here would hide that header.
