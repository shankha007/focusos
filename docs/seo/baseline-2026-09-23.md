The LCP element is the hero's intro paragraph, not the `<h1>` — both sit behind the same Framer
Motion `opacity: 0` entrance, which is what task 2.3 addresses. A Lighthouse SEO score of 100 is
worth reading correctly: it means the one page is technically well formed. It says nothing about
whether the site has pages worth ranking, which is what the rest of the plan is about.

Failing audits worth keeping in view:

- `unused-javascript` — about 24 KB estimated saving.
- `render-blocking-insight`, `network-dependency-tree-insight`.
- `max-potential-fid` — 160 ms.
- `color-contrast` and `label-content-name-mismatch` — accessibility, not SEO, but both are real and
  neither is in the SEO plan. Worth their own branch.

Twenty impressions is what a site nobody links to yet looks like, and that is the point of writing
it down. Position 9.5 across those impressions is close to meaningless at this volume — a handful
of queries, most of them almost certainly the brand name, which a site ranks for by default.

One caveat on how these read. The property was verified only days earlier, and release 1 (phase 1 —
title, description, H1, structured data) merged to `main` on the same day these were recorded,
before Google had recrawled the page. So these numbers describe the *pre-phase-1* page, which is
what a baseline should be, but the window they were measured over ends the day the change shipped
rather than comfortably before it.

## Release dates

The plan originally held every phase for one release. Verifying Search Console changed that: Google
was about to crawl the site properly for the first time, and there was no sense spending that window
indexing a homepage whose `<h1>` never said "Pomodoro timer" — then changing the title on an
already-indexed page, which costs weeks of flux. So the work ships in two.

| Release | Contents | Date |
| --- | --- | --- |
| 1 | Phase 1 — on-page copy, metadata, structured data, crawlable section links | 2026-09-23 |
| 2 | Phases 2–4 — crawl hygiene, LCP, generated sitemap, IndexNow, landing timer, keyword pages | — |

Every later comparison is measured from the release that contains the change being judged.
